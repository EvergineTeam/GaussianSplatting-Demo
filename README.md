# Gaussian Splatting using Evergine

In this Gaussian Splatting sample you can explore Gaussian Splatting technology using Evergine. You can navigate through a Gaussian Splatting scene and use this code base to extend and explore new possibilities.
We have created a code example that showcases a small Roman bridge captured with a drone and reconstructed as a Gaussian Splatting model. In the example, users can orbit around the model to visualize how the trained model can generate the bridge from any viewing angle. The images generated are synthetic, meaning that a specific camera angle may never have been captured in the original drone footage, but the AI model is able to predict it.

![Gaussian Splatting demo](Screenshots/GaussianSplattingDemo.jpg)

## Build and Run

Just open the Visual Studio OpenGL solution and start debugging the project.

### Controls

* Mouse left button: Orbit
* Mouse scroll: Zoom in/out
* Mouse middle button: Panning
